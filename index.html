Vue DevTools UnlockerEnable Vue DevTools in production

Browser extension that unlocks Vue DevTools on production sites for Vue 2 & 3.

Get Started 👆
View on GitHub

  • Unlock DevTools in Production

    Enable the Vue panel on production sites without changing your app code.

  • Vue 2 & Vue 3 Support

    Detects the Vue version automatically and unlocks DevTools for both major versions.

  • Vue Version Insight

    Shows the detected Vue.js version so you can confirm what is running in production.

  • Pinia State View

    Shows Vue 3 Pinia stores and state when the runtime Pinia instance is available.
